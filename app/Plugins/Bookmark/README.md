# 북마크 (읽기 목록)

회원이 마음에 드는 글을 저장해 두고 나중에 모아 보는 플러그인입니다.

## 사용 방법

- **저장/해제**: 글 상세 화면의 공감 버튼 아래 북마크 버튼을 누릅니다. 로그인한 회원만 쓸 수 있고, 다시 누르면 해제됩니다.
- **모아 보기**: 로그인 후 **내 정보** 화면 상단의 **내 북마크** 버튼, 또는 `/my/bookmarks` 로 들어갑니다. 최신 저장 순으로 20개씩 보입니다.

## 동작 규칙

- 북마크는 **회원별로 따로** 저장됩니다. 다른 회원의 북마크는 보이지 않습니다.
- 목록에는 지금 읽을 수 있는 글만 나옵니다. 숨김·삭제된 글, 비밀글, 읽기 권한이 없는 글은 빠집니다.
- 저장해 둔 글이 나중에 숨겨져도 북마크 행은 남아 있고, 목록에서 빼기는 언제든 할 수 있습니다.

## 관리자 안내

- 활성화하면 `bookmark_items` 테이블이 만들어집니다. 비활성화해도 데이터는 **유지**되고, **제거**하면 테이블과 데이터가 함께 삭제됩니다.
- 설정 항목은 없습니다.
- 글 상세의 북마크 버튼은 위젯 슬롯 `post_actions` 에 붙습니다 (회원별 상태라 캐시하지 않음).

## 메뉴 노출

`plugin.json` 의 `menu` 항목이 활성 상태일 때 **내 정보** 화면 상단에 버튼으로 표시됩니다. 플러그인을 끄면 버튼도 사라집니다.
